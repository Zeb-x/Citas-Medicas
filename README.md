--Instalacion y configuracion

Para desarrollar y ejecutar este programa, es necesario tener instalado Java JDK 11 e 
IntelliJ IDEA o caulquier IDEA que pueda ejecutar el codigo en java.  
Asegurate de configurar el SDK en IntelliJ y clonar este repositorio en tu PC.

--Uso del programa

En este programa, se dara de alta una lista de medicos y sus especialidades con el 
fin de poder programar citas para pacientes incluyendo fecha y hora de la cita.
